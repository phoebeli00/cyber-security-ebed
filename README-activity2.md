# Activity 2 · Choosing Among Tools

Standalone page: `choosing-tools.html` (plain HTML/CSS/JS, no build step).
Icons: `assets/icons/*.svg` (pixel-style, loaded by relative path).

## Add to the training site
1. Copy `choosing-tools.html` to the site root, next to `tool-selection.html`.
2. Copy the `assets/icons/` folder to the site root.
3. Add this link to the "Course activities" nav on the other pages:
   `<a href="/choosing-tools.html">Activity 2 · Choosing Among Tools</a>`

The project guide, people, and files are fictional. Confirm the tool examples
(CMU Box, CMU Slack) with CMU ISO before using this with learners.
